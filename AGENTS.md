# LightRhythm development workflow

- Work on the appropriate feature branch. Do not merge into main unless the user explicitly requests it.
- After each completed, validated implementation step, commit the relevant code, tests and documentation, and upload the commit to the corresponding GitHub branch.
- Report the uploaded branch and commit. If uploading fails, state that clearly and preserve the local work.
- Keep private photos, machine configuration, build outputs and generated local reports out of commits.
