# 新样例的局部条纹回退 v9（2026-11-26）

用户标注：14/15/17/18 为横纹，16 为摩尔纹；19 的屏幕上有横纹，地面规则纹理是天花板反射。13 继续作为百叶窗反例。所有照片仅在本机提供，不提交、不打包进 APK。当前输出不能反过来作为标签。

## 实现

保留 v8 的整行判据、128/64 局部窗口及跨行持续性约束；在这两种局部尺度均失败后独立尝试 256 窗口。它能覆盖长周期的至少四次重复，使 14 原图的约 48 行条纹不再因小窗口长度不足而漏检。不同尺度不混合计票。

全图与原有局部检测均未触发时，再以高饱和颜色连通区域提出矩形候选。16 像素网格按主色计数（亮度最大通道至少 50、色差至少 max(32, 最大通道×0.4)、单格至少 40% 有效像素）；只闭合一格间隙。连通区域至少六格、包围框填充至少 35%，最多检查八块。它不识别“屏幕”物体，普通彩色内容也可能提出候选。

每个矩形按横向、竖向分别检查四个真实的交叉条带；同色像素的亮度、R−G、B−G 两种四分位数抑制白色文字和边框。各条带检查至少四周期、幅度、局部峰值、半周期差异、短周期倍频；三点平滑及两倍 RMS 限幅抑制孤立尖峰。允许候选相关性比配置低 0.15（下限 0.5），但仍要求配置指定的空间支持率（默认 3/4）、至少两条达到严格相关门槛、支持条带的平均相关性达到严格门槛（默认 0.65）。一个条带的不同通道/分位数只能贡献一票。保留配置的幅度和最少周期限制，未降低旧整行/局部判据。

新增 `BandingResult.localizedStripes`，矩形与周期均使用输入 Bitmap 像素坐标；`StripeAxis.HORIZONTAL` 的周期单位是行，`VERTICAL` 是列。原来的行轮廓、行残差和周期字段继续保持整行含义。新证据沿用 `SUSPECTED_LOCAL_BANDING`，不生成整行修复映射；页面展示方向和局部周期，ViewModel 与处理器均阻断整行修复。像素入口版本为 `row-region-periodicity-v9`，中性背景入口为 `row-region-broad-v9`。

摩尔纹算法保留 `local-chroma-recurrence-v4`。本轮尚未得到能可靠解决 16 且保持反例的改动，不提交实验性的弱颜色/频谱回退。
