## 改动

一次逐行读取同时统计四个纵向区域的 Y、R−G、B−G。颜色差值编码为 `(通道差)/2+127.5`，保持数值范围 0～255，并抵消共同的灰度明暗变化。

旧明暗分支保留原有规则；新增颜色分支默认搜索到 min(1024, 高度/2)，允许至少两周期的宽色带。颜色分支仍保留 RMS≥2、自相关≥0.65、半周期相关≤−0.15、区域同相相关≥0.7、至少四区中三区支持的判据，没有降低这些阈值。

颜色分支的趋势半径独立固定为 256 行，避免随着最大搜索周期一起扩大去趋势窗口。该固定窗口仍有尺度限制；缩放图片后应记录输入分辨率。候选周期是近似值，局部去趋势和画面内容可能影响峰的位置。

新增 ColorDetectionConfig、ColorBandingEvidence 和 SUSPECTED_COLOR_BANDING。保留明暗字段与颜色字段各自的含义，颜色候选不产生可直接供 B 使用的明暗修复增益。接口见 [检测接口](detection-interface.md)。
