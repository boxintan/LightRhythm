# 检测 v4：排除绕过周期下限的整数倍候选

2026-11-23，feature/detection。

## 复现与修复

原规则只在候选范围内找自相关峰。实际周期小于 minPeriodRows 的重复纹理，也可能在其奇数倍滞后处同时满足高相关、局部峰和半周期反转，从而绕过下限。新增测试在修改前复现两组失败：默认最小周期下的短周期纹理、配置 minPeriodRows=16 后的更短周期纹理。

现在候选周期 p 通过原条件后，再检查 2～minPeriodRows−1 的较短滞后 q。若 p 能被 q 整除，q 自身是达到相关阈值的局部峰，且其相关值不低于 p 的相关值减 0.03，则排除 p。没有降低原有幅度、相关和区域一致性要求。

该规则作用于明暗和颜色分支共用的周期分析。输出字段和坐标含义保持不变，数值判定版本更新为 row-periodicity-v2，启用颜色的组合版本更新为 row-color-periodicity-v4。禁用颜色分支仍使用新版明暗判定，不能视为完整复现历史 v1。
